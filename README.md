# Flower Shop Website

A simple and user-friendly flower shop website developed using HTML, CSS and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Flower product display
- User-friendly interface
- Simple and clean design
- Customer and seller concept
- Responsive web design

## Project Purpose

The purpose of this project is to create a simple platform where customers can view flower products and connect with the flower shop.
